## 源码运行与材料生成

作品运行遵循[评委指南](../../../docs/judge-quickstart.md)。固定本版功能源码可执行 `git checkout 068a22a8a4d1987ac0aac837da22b39c8224417f`；材料目录位于公开主分支，检出功能提交前可另存本目录。

`source/build.mjs` 为PPT生成源，`content.json` 包含逐页讲稿、时长和来源。它依赖Codex内置的 `@oai/artifact-tool` 及演示文稿技能运行时，**不属于作品运行依赖**。有同一运行时的环境可在仓库根目录设置 `RUNTIME_NODE_MODULES`、`PRESENTATIONS_SKILL_DIR`、`PRESENTATIONS_PYTHON`，再运行：

```bash
DECK_REV=04 node submission/finals-2026-10-29/roadshow-v3/source/build.mjs
```

输出先进入忽略的 `build/finals-ppt-v3/`；最终文件必须另行检查后复制至本目录的 `output/`，不得把未完成的草稿当作交付文件。PDF预览由最终PPT逐页高分辨率画面合成。
