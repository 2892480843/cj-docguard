# 决赛答辩稿源文件

10 页、16:9、可编辑图形与文字，配逐页讲稿备注；按备注建议时长约 7 分 15 秒，不等同于已经完成现场计时演练。新版不覆盖初赛 PPT 或视频。

生成需 Node.js 和 `pptxgenjs`（仅材料制作依赖，不是工作台运行依赖）。每页单独导出同步 `createSlide(pres, theme)`；`compile.js` 按序组合，输出上级目录中的 PPTX。可在独立材料制作目录安装依赖后运行：

```bash
npm install pptxgenjs
node compile.js
```

PDF 是本轮实际渲染预览。PowerPoint 的字体回退受宿主影响；中文版按技能默认声明 Microsoft YaHei，英文 Arial，本机没有 Microsoft YaHei，PDF 使用本机可用字体回退。发布前已检查实际 PDF 的十页画面、文字完整性和边界；详情见 [QA.md](QA.md)。

所有运行数字都有明确样本与平台范围。完整套件、源码身份和公开克隆结果以决赛目录的验证记录为准，幻灯片不预填尚未观察到的测试数量或发布成功结论。动态结果变更时应先核实证据，再修改对应页源文件并重新渲染检查。
