## 失败定位与修复

本机 Xcode 已更新，默认 MacOSX27.0.sdk 的 libSystem.tbd 含 `arm64e.x1`，旧仓颉 SDK 链接器报无法识别架构。新增 CJ_DOCGUARD_SYSTEM_SDKROOT / --system-sdk 显式选取已有系统 SDK，原生工具验证并记录规范路径；导出脚本也尊重相同选择。没有修改系统 Xcode 配置、替换仓颉编译器或篡改系统 SDK。

审查中修复：报告字段注入 HTML、切换项目时迟到响应覆盖新项目、大查询 JSON 被界面日志上限截断、不支持状态误标绿色、诊断重复计数、关闭服务未等待任务结束，以及跨项目遗留筛选。
