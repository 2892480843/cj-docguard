# 支持范围与边界

## 已实现

原生核心使用仓颉与 SDK 标准库。JSON/TOML 为限定、严格读取的内置实现；SHA256 为流式内容摘要。语法提取使用真实 `std.ast.cangjieLex` / `parseProgram`，保留显式公共声明、参数、返回类型、注释与 UTF-8 字节位置。支持函数、变量、别名、类/结构体/接口/枚举、显式公共成员、构造器、重载、泛型原始声明。

`SUPPORTED` 只表示支持该语法的提取。类型省略显示 `TYPE_UNKNOWN`；宏、条件编译、extend、公共解构及未覆盖节点显示 `PARTIAL` 及诊断。解析器无法给出结构化错误位置时显示 `0:0`，不猜位置。

构建限于同一包的库文件和登记程序/显式包装片段。执行在冻结快照中，每个例子和版本使用独立程序及日志目录。只使用固定的环境白名单；没有凭据继承、隐式网络安装或任意 README 代码块执行。

## 证据准入

最新登记尝试优先于历史成功；进行中、失败或取消均不能自动回退。每项当前行为证据要求完整阶段字段、控制结果、日志及其内容摘要、原始快照及其清单、环境摘要、实际 SDK/平台匹配和必需断言。当前性以查询时的全项目/工具内容重新读取判断。

严格门禁中的 `COMPILE_ONLY` 仅在配置显式要求 `mode="compile"`、真实编译成功、证据完整且输入匹配时满足该编译要求；不进入运行证据查询。程序执行过但无断言的 `COMPILE_ONLY` 仍不满足必需运行要求。

## 限制

- 当前实测平台为 Darwin-arm64 及 Ubuntu 22.04 Linux aarch64，SDK 1.1.3 / 1.2.0；Linux 原生矩阵、查询及导出主流程已验证，未执行所有 Python 辅助工作流，其他 Linux 架构/发行版未外推。Windows 无进程监督器实现。
- 不包含完整语义分析、自动依赖解析、跨包项目构建、宏展开、远程依赖下载或精细增量影响分析。
- 白名单以外的标准库/第三方导入保守标为闭包未知，即使例子实际运行成功。未知不得晋升当前通过。
- `closed_inputs=true` 是维护者对输入审核范围的声明。读取整个项目并不能证明程序不会访问任何外部输入；审核、导入限制及固定宿主环境是成立前提。
- SDK 身份记录其实际版本、受控环境及 SDK 内 bin/tools/third_party/modules/lib/runtime 的内容，未哈希整个 OS 或 Apple 系统 SDK。SDKROOT 路径记录不等于系统 SDK 不变证明。
- 项目源码、快照或 SDK 在执行过程中被并发修改，会失效或拒绝；前后读取不是文件系统事务，也不能检测中途改变后恰好恢复的任意宿主环境。需要更强隔离时用维护者控制的固定 CI 宿主/镜像。
- 日志必须是 UTF-8；二进制输出无法解释为文本时保留原始受限日志，但不给行为验证成功。
- 链接解析支持行内/完整引用/折叠引用/快捷引用、图片、尖括号自动链接、转义与嵌套括号、可选标题、UTF-8 百分号路径、查询与片段、ATX/Setext 标题、重复标题锚点和 HTML id/name；排除代码与注释，坏路径和不安全协议明确失败。外链离线为 UNVERIFIED。它是经测试的本地检查器，不声称完整 CommonMark/GitHub 渲染兼容；复杂容器结构、Unicode 大小写折叠和完整 HTML 命名实体表仍有限制，未知实体明确未验证。
- 完成记录通过追加编号保持历史；没有签名防篡改系统，不可当作对恶意本地主机的证明。原始记录和日志需由维护者保护。
- 私有原始归档保留真实内容；报告映射已知项目/SDK 路径。发布前仍需维护者审核源码、断言、许可证及日志，不自动上传。
- 早期静态报告的本地文件协议浏览器自动化曾被拒绝，未绕行。当前仓颉 HTTP 工作台已通过真实浏览器桌面和窄屏检查；具体范围见原生工作台验收记录，不能外推所有浏览器。

## 术语

| 术语 | 含义 |
|---|---|
| API / AST | 可调用接口 / 抽象语法树，用结构而非正则猜测识别声明 |
| SDK | 实际编译器、标准库及运行环境 |
| 输入闭包 | 实际影响验证的输入集合；未知外部输入使当前性无法确认 |
| 指纹 | 内容摘要，用于匹配快照与环境，不能替代程序正确性证明 |
| 断言 | 对输出、错误输出或退出码的明确预期 |
| CI 门禁 | 自动判断必需范围是否满足的发布检查 |
| MCP / Skill | AI 调用工具的协议 / 助手可复用的操作指南 |
| CURRENT / STALE / UNKNOWN_CURRENT / FROZEN | 当前匹配 / 已变化 / 无法确定当前 / 明确归档 |
