# 架构与可靠性审阅说明

CJ-DocGuard使用仓颉实现接口提取、配置校验、内容身份、实际执行编排、证据准入、报告、导出及本地 HTTP（网页请求服务）。Bash 负责构建/启动，C 负责 Unix 进程组监督与少量信号桥接；Python 用于辅助测试和只读协议适配，不提供正式网页服务。维护者审核显式登记的本地单包项目后执行验证，助手通过只读协议查询当前有效证据。

## 模块职责

| 文件 | 责任 | 审阅重点 |
|---|---|---|
| [primitives.cj](../src/primitives.cj) | JSON、受限TOML及SHA-256 | 严格类型、重复字段、错误输入与摘要向量 |
| [extractor.cj](../src/extractor.cj) | std.ast公共声明提取 | 源位置、注释、泛型与未支持结构透明报告 |
| [engine.cj](../src/engine.cj) | 内容指纹、固定输入、实际执行及完整报告 | 执行前登记、前后身份核对、最新尝试与阶段日志 |
| [bindings.cj](../src/bindings.cj) | 项目级唯一符号解析与示例绑定 | 所属类型、跨文件同名及重载歧义；持久绑定必须与当前解析身份一致 |
| [links.cj](../src/links.cj) | Markdown 标题/链接及 HTML 静态 URL 提取 | 原始目标与来源行、完整 Setext 标题、未支持语义明确未知 |
| [workbench_native](../workbench_native) | 仓颉本地 HTTP、项目登记、任务、受控源码编辑、查询与导出适配 | 本机绑定、任务串行、版本冲突、日志/取消和原生结果原样呈现 |
| [web](../web) | HTML/CSS/JavaScript 工作台 | 搜索、矩阵、期望/实际断言、全量链接过滤、源码、历史及导出 |
| [evidence.cj](../src/evidence.cj) | 当前性与运行证据准入 | 失败保守处理、精确SDK/平台、完整必需断言 |
| [report.cj](../src/report.cj) | 离线HTML、JSON、Markdown报告 | 完整矩阵分母、转义、快照边界和明确未知 |
| [export.cj](../src/export.cj) | 当前有效单例的冻结源码导出 | 复用准入、拒覆盖、路径边界、实际编译单元 |
| [runner.c](../scripts/runner.c) | Unix子进程组资源监督 | 超时、中断、父进程死亡、后代清理和日志上限 |
| [mcp_stdio.py](../scripts/mcp_stdio.py) | 标准输入输出只读协议适配 | 固定程序/配置、三工具、参数校验和无任意执行工具 |

CLI（命令行工具）负责按命令限制参数。不存在可直接执行README任意代码块的入口，也不存在助手任意路径或命令执行工具。路径/权限和闭包限制见[支持范围](support.md)。监督器不能隔离任意恶意程序，执行授权和输入审核是前提。

## 数据流与变更边界

配置及显式源文件经过审核后生成内容清单与公共声明。verify先登记尝试，再从冻结输入编译、运行并核对断言，最后复核输入与环境。query重新读取当前输入和实际SDK，按例子及版本选择最新尝试。export从满足同一准入的冻结快照生成独立源码，避免拼接当前工作区与历史结果。

保留完整历史并不代表始终使用历史。只读历史统一标为`FROZEN`、`eligible=false`；当前查询拒绝过期、未知、无断言、缺日志和较新失败。查询可写私有探针和锁目录，但不执行登记示例、不修改项目源码。

以下 R12 说明为 2026-10-07 的历史边界；本轮改动与证据另见[决赛发布](../submission/finals-2026-10-29/README.md)。

R12只补当前真实库复用证据与评审材料，原生核心、监督器和构建脚本字节与受测0a4d81e保持。没有为提高通过率改动断言、上游源码或证据规则。

## 2026-10-29 三项修复的数据流

项目级声明先形成完整目录，再把配置示例解析到唯一 `symbol_id`。验证记录持久保存 `binding_status` 和 `symbol_id`；报告、查询、导出继续核对同一身份。同名成员、重载或未知引用产生诊断，历史缺失绑定不得通过显示层回退获得资格。

链接检查同时保留预期 API 锚点检查，并读取实际生成的 `site/index.html`，从其所在目录解析静态 `href`/`src` 等目标。多行 Setext 标题按完整段落生成锚点。重复属性、`<base>` 改写与未支持候选集合保持必需的 `UNVERIFIED`；外链离线保持未验证。严格检查发现输出损坏后，下一次重新生成可以修复输出，两次检查的意义分别保留。

网页通过原生任务读取报告中的链接、断言与绑定结果，不再另行推断通过。详细回归入口为 [native_index.cj](../tests/native_index.cj)、[native_links.cj](../tests/native_links.cj)、[native_bindings.cj](../tests/native_bindings.cj) 和 [test_bindings.py](../tests/test_bindings.py)。

## 性能与资源边界

[R03内存诊断](memory-diagnostics.md)记录受控308次历史、128MB堆的旧失败与修复后查询/验证/检查成功，不代表任意历史规模保证。R05两次只读查询各约4.3秒，是单次测量，不是延迟分布或性能提升。后续先分阶段测量SDK检查、摘要、历史加载和筛选，再决定优化；不得以缓存过期证据提高速度。
