# Dashboard Layout 网页改版

依据用户指定的仪表盘风格，保留现有十页与后端协议。范围为网页结构、样式，以及顶部搜索、任务通知、手机菜单的实际操作。

1. 固定 256px 深色侧栏；白色顶部包含项目选择、公共接口搜索、真实任务通知、本地工作区入口。手机隐藏侧栏，通过菜单展开。
2. 主色 #6366f1，背景 #f9fafb，正文 #111827；12px 面板、8px 按钮和输入框。继续使用离线中文字体。
3. 概览使用四列指标、2:1 测试图表与分布、最近记录表格及工具链信息。图表从实际 results 计算，未提供历史对比时不虚构增长率。
4. 十页共用表单、表格、状态、弹窗、加载/空/错误状态；保留仅编译、过期和失败等真实含义，以及源码/配置草稿。
5. 为数据汇总、搜索、通知、菜单补回归；浏览器检查实际页面、桌面/平板/手机和键盘；保存截图与检查记录后提交同步。

视觉样式通过浏览器截图、三档尺寸和焦点/控件检查验收；新增行为先做可重复的回归测试。

完成：五步均已执行。新增前端回归通过，三档尺寸十页均已检查；实际截图、查询结果与配色记录见 docs/ui/2026-10-29-dashboard/README.md。
