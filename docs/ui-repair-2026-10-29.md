# 本地工作台 UI 修复记录

本轮范围为网页可读性、布局与交互修复；仓颉验证核心、本地服务接口和证据规则未修改。环境为 macOS arm64。

## 实现语言

- `src/*.cj`：仓颉核心，负责声明提取、配置约束、实际执行编排、证据准入、报告与导出。
- `web/`：HTML、CSS 与 JavaScript 浏览器界面。
- `scripts/workbench*.py`：Python 本地 HTTP 服务及任务适配；`scripts/runner.c` 是 C 进程监督器。

因此目前是以仓颉为核心的混合语言工程，不应宣传为全部使用仓颉实现。本轮没有修改赛事语言要求，也不能据此认定赛题合规性。

## 修复

| 问题 | 修改 |
|---|---|
| 页面大量文字仅 10–12px，部分说明颜色偏淡 | 正文和表单字号、说明文字对比度、按钮与标签尺寸、表格留白重新调整 |
| 窄屏长项目名、表格与源码可能挤占布局 | 容器最小宽度、长文本换行、容器内横向滚动与移动导航调整；侧栏可独立滚动 |
| 查询缺失 SDK 报错后，符号和工具选择被清空 | 按项目和页面保存内存草稿，渲染后恢复；不保存文件选择或上传内容 |
| 加载占位页覆盖项目草稿 | 占位页不写回草稿；跨项目隔离，切回后恢复原输入 |
| 表单提交缺少明确的原生语义与请求反馈 | 使用 submit 按钮及 submit 事件，保留浏览器表单校验；请求期间禁用重复操作 |
| 弹窗焦点、标签键盘行为及页面滚动 | 关闭后返回触发按钮或主内容；方向键/Home/End 切换标签；弹窗开启时锁定背景滚动，标题栏固定 |
| 加载时同时出现“尚无报告” | 使用独立加载占位，避免将加载中的项目描述为没有报告 |
| 原始日期冗长或显示 Invalid Date | 本地格式显示时间，异常值明确为“时间未记录” |
| 概览进度条缺少分母、仅编译说明与辅助语义 | 显示运行验证格数和仅编译格数，增加可读的 progressbar 标签；仍明确是快照 |
| 不完整报告缺少 files 字段时接口页异常 | 按空源码集合显示，保留声明详情 |

## 验证

- 修复前实际复现：查询 `get_verified_examples`、输入 `greet`、未填 SDK 后提交，错误后变为 `symbol=''` 和 `tool='list_symbols'`。
- 修复后同一操作保留 `symbol='greet'`、`tool='get_verified_examples'`；登记不存在配置报错后同样保留路径。
- 实际回车发起原生 `list_symbols` 查询；弹窗方向键切到“断言”，Escape 关闭后解锁背景，导出弹窗关闭后焦点返回原触发按钮。
- 项目 A 输入 `/tmp/only-project-a.toml`，切换 B 输入为空，切回 A 恢复原草稿；未执行该路径对应的登记或文件写入。
- 390×844 视口逐页检查九页，均 `documentWidth=390`、`innerWidth=390`；恢复默认视口后重新检查概览。
- 浏览器错误级日志为空；JavaScript 模块语法和 UTF-8 无 BOM 检查通过。
- `node tests/test_workbench_ui.mjs` 通过，包括 18 种有/无报告渲染场景以及日期、部分报告、进度语义、提交按钮等回归。
- 对 7 组主要文字/背景颜色计算对比度，结果 5.35–7.65。仅为所检查色对，不代表已完成全部 WCAG 认证。

本轮使用实际浏览器交互检查表单与布局，未重跑原生全套测试，因为本轮未改动仓颉或 Python 运行行为。原有真实 SDK 验收见工作台验收文档。
